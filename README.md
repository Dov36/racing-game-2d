# Jeu de course 2D

Jeu de course de voitures en 2D, inspiré de Mario Kart et de Trackmania.
Projet de programmation orientée objet (Python, pygame) réalisé par Isaac,
Timothée et Dov.

## Installation

Il faut Python 3.10 ou plus récent.

```bash
git clone <url-du-dépôt>
cd <dossier-du-dépôt>
pip install -r requirements.txt
python main.py
```
